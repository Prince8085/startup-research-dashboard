# Startup Research Dashboard

A web application dashboard for startup research and analytics.

## Features

- Analytics and comparison views
- Dashboard overview
- HR contacts section
- Research management
- Settings and theme provider
- Responsive design with custom hooks
- Placeholder assets for easy customization

## Tech Stack

- Next.js (React)
- TypeScript
- PostCSS
- pnpm

## Getting Started

1. Install dependencies:
   ```bash
   pnpm install
   ```
2. Run the development server:
   ```bash
   pnpm dev
   ```
3. Open [http://localhost:3000](http://localhost:3000) in your browser.

## Project Structure

- `app/` - Main application and API routes
- `components/` - UI components
- `hooks/` - Custom React hooks
- `lib/` - Utility functions
- `public/` - Static assets
